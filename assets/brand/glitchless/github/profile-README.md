# Glitchless

Vibe debugging for your games. Glitchless times every frame and catches every error on your players' devices, turns
it into ranked findings and a dashboard in your game's own terms, and gives your coding agent the same data over MCP
so it can fix what players hit.

| Repo | What it is |
| --- | --- |
| [glitchless](https://github.com/glitchless-gg/glitchless) | The SDKs (Unity, Godot, Unreal, GameMaker, Three.js, Phaser, Babylon.js, PlayCanvas), the server, the dashboard and the MCP server. Free and open source |
| [game-dev-skills](https://github.com/glitchless-gg/game-dev-skills) | Skills for coding agents: stutters, crashes, slow starts, store reviews and analytics, engine by engine |
| [glitchless-deck](https://github.com/glitchless-gg/glitchless-deck) | Send, launch and measure games on a Steam Deck from macOS, Windows or Linux |
| [glitch-arcade](https://github.com/glitchless-gg/glitch-arcade) | Small Three.js games with planted problems, each with its own dashboard |
