# Glitchless

Let your coding agent understand your players. Glitchless records how your game runs and plays on players' devices
(stutters and their causes, errors, where players stop, what they buy), turns it into ranked findings and a dashboard
in your game's own terms, and gives your coding agent the same data over MCP so it can fix what players hit.

| Repo | What it is |
| --- | --- |
| [glitchless](https://github.com/glitchless-gg/glitchless) | The SDKs (Unity, Godot, Unreal, Three.js, then GameMaker, Roblox, Phaser, Babylon.js and PlayCanvas), the server, the dashboard and the MCP server. Free and open source |
| [game-dev-skills](https://github.com/glitchless-gg/game-dev-skills) | Skills for coding agents: stutters, crashes, slow starts, store reviews and analytics, engine by engine |
| [glitchless-deck](https://github.com/glitchless-gg/glitchless-deck) | Send, launch and measure games on a Steam Deck from macOS, Windows or Linux |
| [glitchless-dsh](https://github.com/glitchless-gg/glitchless-dsh) | Glitchless for DeepSeek Harness: the MCP server and the skills as a plugin |
| [glitch-arcade](https://github.com/glitchless-gg/glitch-arcade) | Small Three.js games with planted problems, each with its own dashboard |
